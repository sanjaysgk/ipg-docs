## Inputs

- `ch_reads` — `[meta, [r1, r2]]` from samplesheet

- `ch_gtf` — `[meta, path]` GENCODE GTF

## Outputs

- `sorted_bam` — coordinate-sorted BAM, `[meta, bam, bai]`
- `star_bam_unsorted` — raw STAR output for the second pass
- `infer_experiment_txt` — RSeQC strandedness report
- `versions` — `versions.yml` channel

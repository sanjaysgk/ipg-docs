## Inputs

- `star_bam_unsorted` — raw STAR output from `ALIGN_QC` (used as the second-pass alignment input)
- `ch_reads` — original FASTQs for `FastqToSam`
- `ch_fasta`, `ch_fai`, `ch_dict` — reference FASTA bundle

## Outputs

- `splitncigar_bam` — post `SplitNCigarReads` BAM, `[meta, bam, bai]`
- `versions` — `versions.yml` channel

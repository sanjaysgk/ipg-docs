## Parameters covered

- `--max_cpus`, `--max_memory`, `--max_time` — global resource ceilings
- `--singularity_cache_dir` — shared singularity image cache (Monash uses `/fs04/scratch2/xy86/singularity_cache`)
- Per-process retry strategy (defined in `conf/base.config`)
- Custom config file (`-c` Nextflow flag, NOT a `--param`)

## Parameters covered

- `--input` — samplesheet CSV
- `--outdir` — results directory
- `--multiqc_config` — optional custom MultiQC config
- `--multiqc_logo` — optional custom MultiQC logo
- `--multiqc_methods_description` — optional methods description for MultiQC
- `--email`, `--email_on_fail` — notification email addresses

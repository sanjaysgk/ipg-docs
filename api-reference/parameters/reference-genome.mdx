## Parameters covered

- `--fasta` — primary assembly FASTA (GRCh38, GENCODE-compatible)
- `--fasta_fai` — samtools faidx index
- `--fasta_dict` — GATK4 sequence dictionary
- `--star_index` — STAR genome index directory (built with STAR 2.7.9a)
- `--gtf` — GENCODE primary-assembly annotation GTF (v44 in the legacy pipeline)
- `--rseqc_bed` — BED12 for RSeQC `infer_experiment.py`

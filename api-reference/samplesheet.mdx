## What this page will cover

| Column | Required | Description |
|---|---|---|
| `sample` | yes | Sample identifier; samples with the same name across rows are concatenated |
| `fastq_1` | yes | Path to R1 FASTQ (gzipped) |
| `fastq_2` | no | Path to R2 FASTQ for paired-end (omit for single-end) |
| `strandedness` | no | `forward` / `reverse` / `unstranded` (auto-detected by RSeQC if omitted) |

Plus: examples for single-end, paired-end, and multi-lane sequencing.

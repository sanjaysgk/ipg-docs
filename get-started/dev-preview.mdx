## What this page will cover

- Pixi env with Node 22 (`pixi add nodejs=22.*`)
- `pixi run npx mint dev` on a Monash M3 interactive node (`smux`)
- SSH tunnel from laptop to compute node through `m3.massive.org.au`
- Two-hop fallback when single-hop tunnels refuse
- Common gotchas (port in use, hostname changes between sessions)

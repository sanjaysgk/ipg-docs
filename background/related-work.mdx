## What this page will cover

### Tools NOT yet ported (Phase 2 → `ipg-origins`)

| Tool | Language | Original purpose |
|---|---|---|
| `filter_FPKM.c` | C | Filter StringTie transcripts by FPKM |
| `origins.c` | C | Classify cryptic peptide origin (intron / UTR / frameshift / novel ORF) — **the biological interpretation step** |
| `msDot.c` | C | Compute MS spectrum dot products |
| `db_compare.R` | R | Compare PEAKS results across two databases |
| `db_compare_v2.R` | R | Enhanced db_compare with ambiguity classification |

These will land in the planned [`sanjaysgk/ipg-origins`](https://github.com/sanjaysgk) sister pipeline. The current `sanjaysgk/ipg` covers steps 1–31 (database construction); `ipg-origins` will cover MS search → peptide classification → origin assignment.

<Note>
**`sanjaysgk/ipg`** is the Nextflow / nf-core port of the immunopeptidogenomics database-construction pipeline first published in **[Scull et al. 2021, *Mol Cell Proteomics*](https://doi.org/10.1016/j.mcpro.2021.100143)**. This documentation site is the canonical reference for installing, running, and understanding it.
</Note>


## What this pipeline does


`sanjaysgk/ipg` consumes paired-end RNA-seq reads and produces a **sample-specific, three-frame translated protein FASTA database** suitable for searching tandem mass spectrometry spectra to discover cryptic peptides — peptides arising from non-canonical translation events that aren't in standard reference proteomes.

It is a faithful nf-core port of a 31-step legacy bash pipeline that combines `STAR`, `StringTie`, `gffcompare`, `GATK4` (BaseRecalibrator, Mutect2, FastaAlternateReferenceMaker), `gffread`, and a small set of custom C tools (`curate_vcf`, `revert_headers`, `alt_liftover`, `triple_translate`, `squish`) authored by **Katherine E. Scull**.

```mermaid
flowchart LR
  R[Paired FASTQs] --> A1[STAR 2-pass]
  A1 --> A2[RSeQC strand]
  A2 --> A3[Sort BAM]
  A3 --> T1[StringTie]
  T1 --> T2[gffcompare]
  T2 --> B1[Mark duplicates]
  B1 --> B2[SplitNCigarReads]
  B2 --> Q1[BaseRecalibrator x2]
  Q1 --> Q2[ApplyBQSR]
  Q2 --> M1[Mutect2]
  M1 --> M2[FilterMutectCalls]
  M2 --> M3[curate_vcf]
  M3 --> D1[FastaAlternateRef]
  D1 --> D2[alt_liftover]
  D2 --> D3[triple_translate]
  D3 --> D4[squish]
  D4 --> D5[(cryptic.fasta)]:::deliv

  classDef deliv fill:#16A34A,color:#fff,stroke:#0E7C3D,stroke-width:2px;
```

The deliverable is `<sample>_cryptic.fasta` — feed it to PEAKS or any FASTA-compatible MS database search engine.
